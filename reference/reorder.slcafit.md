# Reorder Latent Class Membership of Latent Class Variables

Reorders the latent class membership for specified latent class
variables in an `slcafit` object.

## Usage

``` r
# S3 method for class 'slcafit'
reorder(x, ...)
```

## Arguments

- x:

  an object of class `slcafit`.

- ...:

  additional arguments specifying the new order for the latent class
  variables.

## Value

A modified `slcafit` object with the latent classes reordered according
to the specified order.
