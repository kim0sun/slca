#### Boundary-zero investigation (2026-10-24)

At the all-41-constrained starting parameters, all 1004 observation log
likelihoods are finite, but 2487 marginal posterior entries are NaN. In
`src/downward.cpp:71`, a zero child-subtree likelihood gives both
`ulambda[l] = -Inf` and `jlambda[l] = -Inf`; their subtraction produces NaN.
For example, observation 1 has this case at SUB_98 state 4 on the edge to
SMK_98, while its total log likelihood is -13.1426. Thus this reproduced
failure is a zero-probability arithmetic defect, not impossible observed data.
NaNs in score reference columns are intentional and were not used as the
criterion for this diagnosis.

Only a temporary source copy was modified: if `jlambda[l] == R_NegInf`, set
the corresponding joint log probability to -Inf and skip its contribution.
An independent R probability-scale message calculation multiplies sibling
contributions explicitly instead of dividing by the zero subtree message.
It uses the native leaf likelihoods, but independently recomputes all internal
messages and posteriors. Agreement at the constrained starting point:

- Maximum observation log-likelihood discrepancy: 7.11e-15.
- Maximum marginal posterior discrepancy: 1.07e-14.
- Maximum joint posterior discrepancy: 7.89e-15.
- NaN posterior entries after temporary guard: zero.

With this temporary guard, the all-41-constrained fit converges (EM TRUE).
Relative to the original unconstrained bundled fit, log likelihood changes
by +4.34e-8, probabilities by at most 1.20e-6, and modal assignments do not
change for any latent variable. Numerical information rank is still 73 of
76, so the standard-error warning remains. Fixing 41 parameters changes AIC

## Reproduced findings

1. **Regression offsets are ignored.** `regress(f, l ~ x + offset(o))`
   produces exactly the same coefficients as `regress(f, l ~ x)`. The same
   modal binary outcome in `glm()` changes coefficients by 0.08851994 with
   the offset. Without offsets, SLCA and GLM coefficients differ by only
   7.24e-8. The model frame accepts offsets but the likelihood never uses
   `model.offset()`. See `R/regress.R:212` and `R/regress.R:215`.
   Reject unsupported offsets or implement them explicitly; do not accept
   them silently.

2. **Re-estimation does not inherit zero constraints.** After
   `constrained <- estimate(m, d, fix2zero = 3)`, calling
   `estimate(constrained)` drops the constraint indices. The example's
   parameter count changes from 8 to 9 and AIC increases by 2, while the
   formerly fixed probability remains zero. The default `fix2zero = NULL`
   is forwarded instead of the object's constraints. See `R/estimate.R:77`.
   Passing `fix2zero` explicitly avoids this particular omission. Decide
   and document whether omitted versus explicitly NULL should differ.

3. **Reusing a fitted object with a new category count returns an invalid fit.**
   Changing one binary item to three categories and calling `estimate(f, d)`
   returns log likelihood NA and all 20 stored parameters NA, with EM FALSE,
   rather than a clear validation error. Fitting the same data from the model
   definition gives finite log likelihood -902.8913 and EM TRUE. Old parameters
   are reused after recomputing dimensions without a compatibility check.
   See `R/estimate.R:68` and `R/estimate.R:79`. No sanitizer fault was detected
   in this isolated case. Reject incompatible reuse or require a new initial
   parameter vector with verified dimensions and category semantics.

4. **Unknown control names corrupt valid settings.**
   `control = list(typo = 2, em.iterlim = 5)` produces `em.iterlim = 2`.
   It emits a generic replacement-length warning, not a useful unknown-option
   warning. `match(..., 0L)` is filtered with `!is.na()` rather than excluding
   zero. See `R/estimate.R:63`. Validate names before assignment.

5. **Large covariate scales break regression with an unrelated error.**
   Multiplying the otherwise working covariate by 1e6 returns
   `invalid 'type' (list) of argument`. Direct exponentiation in the softmax
   and the empty-optimizer-result path need attention. See `R/regress.R:220`
   and `R/regress.R:327`. Stable log probabilities, explicit optimizer failure
   handling and appropriate scaling diagnostics need their own tests.

6. **Rank-deficient models receive misleadingly ordinary uncertainty output.**
   A regression with an all-zero design column returns coefficient 0 and SE 0
   without a rank warning. A two-class, two-binary-item model has five free
   parameters but information rank three, yet returns finite SEs without a
   rank warning. See `R/regress.R:339` and `R/methods.R:353`. Pseudoinverse
   output is not evidence that all parameters are identified. Add diagnostics
   and define uncertainty behavior for deficient directions.

7. **Legacy fit compatibility is incomplete.** `compare()` rejects identical
   observations when only `yu` encoding differs, and also when only saturated
   convergence metadata is absent. `estimate(legacy)` reuses the old `y` and
   fails with the new response-range error. These are controlled errors,
   not incorrect test statistics or sanitizer faults. See `R/diagnostic.R:335`
   and `R/estimate.R:70`. Distinguish observed-data equality from internal
   caches/diagnostics, and normalize legacy input before continued estimation.

8. **Prediction matrices can silently lose their supplied column identities.**
   A reversed-column matrix with incorrect nonempty names is relabeled by
   position rather than rejected. In the example 36/300 classifications change
   without warning. See `R/methods.R:401`. Define positional handling for
   genuinely unnamed matrices separately from incorrectly named matrices.

9. **Zero-LR bootstrap plotting errors.**
   `compare(f, f, test = "boot", nboot = 2, plot = TRUE)` errors with
   `missing value where TRUE/FALSE needed`. The near-zero-LR shortcut stores
   `Inf` and the plotting branch tries to histogram it. See
   `R/diagnostic.R:364` and `R/diagnostic.R:442`. Skip or explicitly handle
   a shortcut result with no simulated distribution.

Findings 1-6 concern functions unchanged from `a11c1b0`; the prediction branch
and zero-LR plotting code are also unchanged. They are not new defects caused
by replacing the bundled NLSY objects. Finding 7 spans older persisted objects
and the current encoding/metadata transition. No old native likelihood was
executed with incompatible new encodings to infer historical numerical results.

Static follow-up: regression optimizer return codes are not filtered before
selecting the smallest objective. This is visible in source but a distinct
ordinary-scale nonconverged winning fit was not established in this audit;
do not count it as another experimentally reproduced finding.
